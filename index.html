Diagnosis Helper

Observation Meaning Fix
HTTPS custom domain fails server.learnwithchampak.live is not reaching your Worker. Fix Cloudflare Worker Custom Domain or Route.
HTTPS custom works, WSS custom fails Worker is reached, but WebSocket upgrade is failing. Check Worker code and Upgrade handling.
workers.dev WSS works, custom WSS fails Worker code is okay. Custom domain route is the problem. Add Custom Domain in Worker → Settings → Domains & Routes.
workers.dev WSS also fails Worker code is probably wrong. Use the correct WebSocketPair Worker code.
Close code 1006 Abnormal close. Browser did not get a clean WebSocket connection. Check DevTools → Network → WS → Status Code.
Status 101 Success. WebSocket handshake accepted. No route issue. Continue testing messages.
Status 200 Server gave a normal web response instead of WebSocket upgrade. Check Worker upgrade logic.
Status 404 Wrong route or custom domain not attached. Fix Worker route/custom domain.
Status 525 or 526 SSL/TLS issue. Check Cloudflare SSL mode and certificate.
Browser JavaScript cannot directly read the WebSocket HTTP status code after failure. For that, open DevTools → Network → WS → failed request → Headers.

Recommended Worker Code

Use this Worker code for the server side while testing. 

export default {
  async fetch(request) {
    if (request.headers.get("Upgrade") !== "websocket") {
      return new Response("Worker alive. WebSocket endpoint ready.", {
        headers: {
          "content-type": "text/plain;charset=UTF-8",
          "cache-control": "no-store"
        }
      });
    }

    const pair = new WebSocketPair();
    const client = pair[0];
    const server = pair[1];

    server.accept();

    server.send("CONNECTED: Worker WebSocket is working.");

    server.addEventListener("message", (event) => {
      server.send("ECHO: " + event.data);
    });

    server.addEventListener("close", () => {
      console.log("WebSocket closed");
    });

    server.addEventListener("error", (event) => {
      console.log("WebSocket error", event);
    });

    return new Response(null, {
      webSocket: client
    });
  }
};
