Debug Checklist


            

                1. Open https://server.learnwithchampak.live/ directly in the browser.
                It should show the plain Worker alive message.
            


            

                2. Open DevTools → Network → WS. Then click Connect.
                The WebSocket request should show 101 Switching Protocols.
            


            

                3. If wss://server.champaksworld.workers.dev/ works but
                wss://server.learnwithchampak.live/ fails, then the custom domain
                or Worker route is the problem.
            


            

                4. If both fail, the Worker code is the problem.
